# 言語の増やし方

言語を一つ足す手順です。牌のページと色のページは `scripts/build_library.py` が書きます。トップページだけは、生成の前に手で作ります。

サイトの根は日本語です。それ以外の言語は `prefix` のディレクトリに置きます。ブラウザの言語では切り替わりません。絵と動画は言語のあいだで共有します。引いた記録は言語ごとのクッキーに残るので、別の言語の山には混ざりません。デザインの選択は `cftf-design` 一つで、言語をまたぎます。

日ごとのページとカフェは、頼まれない限り作りません。デザインは作ります。生成は書かないので、英語のページを写して手で訳します。

## 1. `data/languages.json` に言語を足す

英語かスペイン語のオブジェクトをコピーして、配列の末尾に足します。`prefix` を空にできるのは、サイトの根にある言語だけです。`default` も一つだけです。新しい言語の `days` は false にします。

次の項目を、その言語のものに変えます。

| 項目 | 役割 |
| --- | --- |
| `id` | ファイル名に使う短い識別子。例: `es` |
| `htmlLang` | `html` の `lang` |
| `hreflang` | 相互リンクの言語 |
| `prefix` | URL のディレクトリ。根以外は必須 |
| `switchLabel` | 言語メニューに出る名前 |
| `cookie` | `cftf-` に `id` を続ける。言語ごとに別にする |
| `session` | `cftf-reading-` に `id` を続ける |
| `ogLocale` | `og:locale`。例: `es_ES` |
| `meanings` | `meanings.<id>.js` |
| `cardName` | 牌の名前のキー。例: `nameEs` |
| `colorName` | 色の名前のキー。例: `nameEs` |
| `textField` | 物語ファイル名のキー。例: `textEs` |
| `textSuffix` | 物語ファイルの接尾辞。例: `.es` |
| `punctuation` | 導入文を切る記号。英語とスペイン語は `. ` |
| `lineLimit` | 色一覧の一行の長さ |
| `introLimit` | 導入文の長さ |
| `descriptionLimit` | `description` の長さ |
| `titlePattern` | 物語の1行目に一致する正規表現 |
| `revealPrefixes` | 開示文の先頭と `Lucky Color:` |
| `shareText` | 共有文。色名は `{color}` |
| `copy` | 引き画面の文言 |
| `pages` | 牌ページと色ページの文言 |
| `footer` | 問い合わせとプライバシーへのリンク |

入れ子の言語の `data` は `/data` です。プレビューのサーバはリポジトリのルートで動かすので、この絶対パスが `data/` を指します。

`latinSubtitle` が false のとき、一覧の牌名に英語名は添えません。`fontFamily` が空なら、本文は明朝のままです。中国語のように別の書体が要るときだけ、`fonts` に Google Fonts のクエリを書き、`fontFamily` にその書体を書きます。トップのフォントリンクは、生成時に `fonts` から書き換わります。

`footer` には問い合わせとプライバシーを、その言語のラベルで入れます。問い合わせのページがなければ英語の `/en/contact/` を、プライバシーは `/privacy/` を指します。GitHub は `scripts/build_library.py` がフッターの末尾に足すので、ここには書きません。

## 2. 原稿を 22 枚と 440 色ぶん書く

### 牌の意味

`public/meanings.en.js` と同じ形で、`public/meanings.<id>.js` を作ります。中身は `window.MEANINGS` です。22枚のそれぞれに `upright` と `reversed` を入れます。生成はこのファイルを Node で読みます。

### 牌と色の名前

22枚の `data/<牌>/card.json` に、次を足します。

- 牌そのものに `cardName` のキー。例: `"nameEs": "El Loco"`
- 正位置10色、逆位置10色のそれぞれに、`colorName` と `textField`

`textField` の値は、これから書く物語ファイルの名前です。例: `"textEs": "white.es.txt"`

### 色の物語

ファイルは `data/<牌>/<色><textSuffix>.txt` です。22枚 × 20色で 440 ファイルです。色のスラッグは、すでに存在する英語のファイル名（`white` など）を使います。新しい色は作りません。

形は `data/the-fool/white.es.txt` に合わせます。

1. 1行目は、牌名、`―`（U+2015）、向きです。`titlePattern` がこの行に一致するようにします。スペイン語の例は `El Loco ― Al derecho` で、パターンは `[―—-]\s*(Al derecho|Al revés)\s*$` です。
2. 本文は要約しません。神話、地理、歴史、天候、生活の道具を織り、その色へ着地させます。
3. 結びの直前に、その言語の開示文を一行置きます。`revealPrefixes` の先頭と一致させます。例: `El color de la suerte de hoy es Blanco.`
4. その次の行は英語のままにします。例: `Lucky Color: White — #FFFFFF`。ダッシュは `—`（U+2014）です。色名は英語の CSS 名、HEX はその色の値のままです。
5. `revealPrefixes` には、開示文の先頭と `Lucky Color:` の両方を入れます。生成は、この接頭辞で始まる行を色一覧の一行から外し、物語の結びとしては残します。

開示文のあとに短い結びの文が続いてもかまいません。`Lucky Color:` の行そのものは、英語の色名と HEX のまま残します。

## 3. トップページを、生成の前に書く

`public/en/index.html` を `public/<prefix>/index.html` に写し、見える文章を訳します。次をその言語のものにします。

- `html` の `lang` を `htmlLang` に
- `canonical`、`og:url`、`og:locale`、`og:title`、`og:description`
- 意味のスクリプトを `../meanings.<id>.js` に
- 先頭の `sessionStorage` のキーを、その言語の `session` に

`<!-- hreflang -->` から `<!-- /hreflang -->` までと、`</nav>` は残します。生成はこの二つを見つけて、言語メニューと相互リンクを書き換えます。トップが無い言語は読み飛ばされるので、生成より前にファイルを置きます。

二十二枚の短い説明は、意味ファイルの各向きの最初の文にします。`latinSubtitle` が false なら、牌名に英語名は添えません。

ロゴのリンクは `./` にして、その言語のトップへ戻します。スタイル、アプリ、言語設定のスクリプトは、ひとつ上の `public/` を相対パスで指します。

## 4. 生成して確認する

リポジトリのルートで実行します。

```sh
python3 scripts/build_library.py
```

これで全言語の牌ページと色ページ、`public/languages.js`、`public/lang.css`、`public/sitemap.xml` が書き換わります。各トップの言語メニューと hreflang も書き換わります。同じ牌と色のページは、言語同士で指し合います。`default` の言語が `x-default` です。

サイトマップのデザイン URL は、そのディレクトリに `index.html` があるものだけ残ります。デザインのページは次の節で置くので、置き終わってから、もう一度この生成を実行します。生成はデザインの本文、言語メニュー、hreflang を書き換えません。

プレビューも、リポジトリのルートで始めます。

```sh
python3 -m http.server 8741
```

`http://127.0.0.1:8741/public/<prefix>/?test=1-1` を開きます。最初の数字は愚者から数えた牌、次の数字は色です。1 から 10 が正位置、11 から 20 が逆位置です。`1-1` は愚者の正位置の最初の色です。

確認することは四つです。

- 結びに、英語の `Lucky Color:` の行が残っている
- ロゴを押すと、その言語のトップへ戻る
- 言語メニューが開き、他の言語と行き来できる
- 二十二枚の牌ページと、各牌の20色が開ける

この生成は本番へは出しません。

## 5. デザインのページを手で書く

一覧が1枚、様式が32枚です。`public/en/design/` を `public/<prefix>/design/` に写します。ディレクトリ名（`editorial-luxury` など）はそのままです。絵のファイルは写しません。一覧の絵は `public/design/<様式>.jpg`、様式の中の絵は `public/design/<様式>/<牌>.jpg` にあり、言語のあいだで共有します。

### 訳す

一覧では、見出し、リード、32様式の名前、画像の alt、フッターのラベルを訳します。

様式のページでは、見出し、リード、目次とキャプションの牌名、画像の alt、一覧へ戻る文、使うボタン、フッターのラベルを訳します。

`latinSubtitle` が true の言語は、キャプションの牌名のあとに英語名を `<em>` で添えます。中国語の例は `愚者<em>THE FOOL</em>` です。false なら牌名だけにします。

使うボタンは、その言語の「使う」と「やめる」を `data-use` と `data-stop` に書きます。ボタンの中の文字は `data-use` と同じです。`data-design` は英語の様式名のままです。

### 残す

次は、写した英語のページから変えません。

- 絵のパス。一覧は `../../design/<様式>.jpg`。様式のページは `../../../design/<様式>/<牌>.jpg`
- `deck.css`、`lang.js`、`use.js` は `public/design/` を指す。新しい言語用には作らない
- 図の `id` と牌のアンカー（`#the-fool` など）
- ロゴの文字 `Colors for the Fool`。一覧のリンクは `../`、様式のリンクは `../../` で、その言語のトップへ戻る
- 一覧へ戻るリンクは `../#<様式>`

`html lang`、canonical、`og:locale`、`og:url`、`og:title`、`og:description`、ナビの `aria-label` は、その言語のものにします。別の書体が要るときは、一覧と32様式のフォントリンクも変えます。中国語は Noto Serif TC を足しています。

問い合わせのページがなければ、一覧のフッターは `../../en/contact/`、様式のフッターは `../../../en/contact/` を指します。プライバシーは、一覧が `../../privacy/`、様式が `../../../privacy/` です。

### 既存のデザインにも足す

新しい言語のページだけでなく、日本語、英語、中国語の一覧と32様式にも、その言語へのリンクと hreflang を足します。`x-default` は日本語のデザイン URL のままです。

トップページにも、デザイン一覧へのリンクを足します。本文の短いリンクと、フッターの一語です。

### 確認する

デザインを置き終えてから、もう一度 `python3 scripts/build_library.py` を実行します。`index.html` がある一覧と様式だけがサイトマップに入ります。

`http://127.0.0.1:8741/public/<prefix>/design/` を開きます。確認することは四つです。

- 一覧から一つの様式を開くと、共有している絵が出る
- 使うボタンが、その様式を `cftf-design` に入れる。別の言語の引き画面でも、同じ絵になる
- 言語メニューが、同じ様式の別の言語を開く
- 戻るリンクが、一覧のその様式へ戻る
