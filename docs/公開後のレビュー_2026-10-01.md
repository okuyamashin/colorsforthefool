## 足したほうがよいもの（優先度が高い順）

### 1. プライバシーポリシー

- Google Analytics（G-NQ38VZSM7B）を入れているので、Googleの規約上、アクセス解析を使っていることの記載が必要。
- 短いページで十分。フッターからリンクする（日本語・英語とも）。

### 2. シェア機能とシェア用の画像

- 引いた結果の画面に「この結果をシェア」を置く。色のページの固定URLがすでにあるので、それを共有するだけで作れる（スマホでは navigator.share、PCでは X や LINE のリンク）。
- og:image がカードの絵（縦長の1024×1536）なので、X や LINE では上下が切れて表示される。横長（1200×630）のシェア用画像を、ビルド時に絵と色名を合成して作る。
- twitter:card（summary_large_image）の指定を足す。

### 3. 画像の重さ

- 絵が1枚あたり500KB前後（1024×1536）。data/ の jpg は全部で約930枚、約243MB。
- スマホでの表示速度は Google の評価にも関わる。
  - WebP にするか、表示サイズに合わせた縮小版を作る
  - 画面の下のほうにある画像に loading="lazy" を付ける

### 4. 色のページに「引いてみる」導線

- 今はパンくずの「カードを引く」だけ。
- 検索から色のページに来た人向けに、物語の下に「あなたの今日の一枚を引く」のようなボタンを置く。

## 細かいけれど、やっておくと良いもの

- 色のページの h1 が「ゴールド」だけ → 「世界（正位置）のラッキーカラー、ゴールド」のようにする。
- 構造化データに datePublished と author を足す。パンくずの BreadcrumbList を追加する。トップには WebSite を入れてもよい。
- canonical が .../gold/index.html の形 → .../gold/ に揃えるとすっきりする（今のままでも統一されていれば問題はない）。内部リンクも合わせる。
- 404ページを作り、トップやカード一覧に戻せるようにする。
- 運営者の情報：フッターは「Engawa Inc.」と GitHub だけ。短い「このサイトについて・運営者」のページがあると信頼感が上がる。
- Search Console に日本語版・英語版を登録し、sitemap を送信する（まだなら）。

## 追記：公開サイトを実際に動かして確認した結果（2026-10-01）

確認方法：Claude の内蔵ブラウザで公開サイトを開き、スマホ幅（375×812）で表示と動作を確認した。

### 見つかった問題

1. 存在しないURLで「403」のXMLが出る
   - /privacy/ や /nonexistent-xyz のような無いページを開くと、S3 の AccessDenied（application/xml、ステータス403）が素のまま表示される。
   - Google からも「ページが無い（404）」ではなく「アクセス拒否（403）」と見える。
   - 対応：CloudFront のカスタムエラーページで、403 と 404 を /404.html に向け、レスポンスのステータスを 404 にする。上の「404ページを作る」と一緒に対応する。

2. 2回目のタップの案内が、まだ「もう一度タップすると、今日の色が開きます」のまま
   - 実際に引いた例：恋人（正位置）。2回目のタップで物語の冒頭へスクロールし、ラッキーカラー（ラベンダーブラッシュ）が出てくるのは、長い物語の最後。
   - SEOと今後の方針.md で話した「ラッキーカラーを先に見せる」「案内を『今日のラッキーカラーが開きます』にする」は、まだ入っていない。

3. 結果の画面にシェアボタンがない
   - 物語の最後に「この色のページ」へのリンクはある。そのすぐ隣にシェアボタンを置くのが自然な位置。

### 問題なかったこと

- 見た目：カードの絵と色のシーンの世界観がよく出ている。
- 表示速度：トップの読み込み完了まで約0.3秒（今回の計測）。
- 色のページ（/cards/the-world/gold/）は、index.html の有無どちらのURLでも表示される。
- 英語版のトップ（/en/）も正しく表示される。
- HTML、sitemap.xml は Brotli で圧縮されて配信されている（キャッシュは max-age=300）。
- robots.txt、sitemap.xml は正しく公開されている。

### 補足

- 画像は1枚500KB前後（例：gold.jpg 約502KB、キャッシュは max-age=86400）。今回の計測では速かったが、回線の遅いスマホでは重く感じる可能性は残る。
- 動作確認で1枚（恋人）引いたので、確認に使ったブラウザには「引いた記録」が残っている。
