# 小さなタロットの足し方

カフェ・タロットと同じ、正位置だけの小さなタロットを足す手順です。見本は `public/demo/cafe/` です。

この種のページは `scripts/build_library.py` が書きません。色も逆位置も言語の切り分けも無く、引いた記録も残りません。正位置を一枚引き、読みの最後は店の一品に着地します。

言語を足す手順は [言語の増やし方](言語の増やし方.md)、様式を足す手順は [デザインの増やし方](デザインの増やし方.md) です。

## 1. 店を一つ写す

`public/demo/cafe/` を `public/demo/<スラッグ>/` に写します。中身は `index.html`、`demo.js`、`demo.css`、牌ごとの `.txt`、`img/` です。ロゴは `../../` で日本語のトップへ戻します。スタイルは `../../styles.css` と、その店の `demo.css` です。

`index.html` のタイトル、説明、canonical、`og:url`、`og:image`、店の見出しと短い文、店内の写真、最後に出す一品の写真を、その店のものにします。問い合わせへの一文は、カフェでは「あなたのお店のオリジナル、タロット占いを作ることができます。」です。頼まれた店の文に変えます。

## 2. 二十二枚の読みを書く

ファイル名は牌のスラッグのままです。例は `the-fool.txt` です。`demo.js` の `parseReading` が、この形だけを読みます。

- 1行目は、牌の日本語名、全角括弧の英語名、`正位置`。例は `愚者（The Fool）正位置` です。
- 空行を一つ置きます。
- 本文は要約しません。最後は、その店の一品に着地します。カフェでは、どの牌もカフェラテです。

逆位置は作りません。`demo.js` の `DECK` は大アルカナ二十二枚のままにします。

## 3. 絵を置く

`img/` に、裏 `back.jpg`、店内の写真、一品の写真、二十二枚の牌を置きます。牌のファイル名は `.txt` と同じスラッグです。`demo.js` は `img/<牌>.jpg` を開きます。一品の写真は `index.html` の読みの末尾にあり、スクリプトは差し替えません。

## 4. 日本語のフッターから開く

リンクを足すのは日本語だけです。`data/languages.json` の日本語の `footer` に、`/demo/<スラッグ>/` とその店の名前を入れます。牌ページと色ページは、次の生成でこの一覧をフッターに書きます。

手で書いてあるページには、生成がフッターを足しません。日本語の `public/index.html` と、日本語のデザイン一覧、各様式のフッターに、同じリンクを足します。英語、中国語、スペイン語には入れません。

サイトマップには入りません。`scripts/build_library.py` は `/demo/` を書き出さないので、カフェと同じく外したままにします。

## 5. 確認する

リポジトリのルートで実行します。

```sh
python3 scripts/build_library.py
```

日本語の牌ページと色ページのフッターにリンクが足されます。デザインとトップのフッターは、第4節で手で足したものが残ります。この生成は本番へは出しません。

プレビューは、リポジトリのルートで `python3 -m http.server 8741` を動かしてから、`http://127.0.0.1:8741/public/demo/<スラッグ>/` を開きます。確認することは三つです。

- 一枚引くと正位置の読みが開き、最後の一品が出る
- 閉じると裏に戻る
- ロゴが日本語のトップへ戻る
