# 配信先の相談（2026-10-01）

毎日の色リールは、インスタ（colors.for.the.fool）へ日本時間6:00に1本出すところまで入っている。このメモは、そのほかの場所に同じものを流すかどうかの相談。

リールは 1080×1920、15秒。文は `data/<card>/<color>.instagram.txt` で、投稿時に先頭へ「西暦○年○月○日」を付ける。

## 結論

毎日の自動投稿はインスタのままにする。次に足すなら YouTube ショートが近いが、全体公開の API には監査が要る。それまでは、すでにあるチャンネルの YouTube Studio から出すほうが短い。

- X には無人の毎日投稿を置かない。人が自分の結果をシェアする導線が合う。
- LINE 公式は週1回の一斉配信。毎日は通数とブロックの両方で厳しい。「今日の色」は、相手から来たときだけ返す応答にする。
- Threads は文章と返信の場所。リールの複製は後回し。
- TikTok は API があり、動画の形も合う。全体公開には監査が要る。

## X

自分のアカウントから公式 API で予約投稿すること自体は認められている。禁止されているのは、ほぼ同じ文の連投、勝手な返信やいいね、フォローの自動化、ブラウザ操作での投稿。人が下書きを見てから出す予約なら、プロフィールの「自動」表示は要らない。人が見ずに毎日出す完全自動なら、自動アカウントであることの表示と、誰が運営しているかの記載が必要。

今のインスタと同じ型（日付、カード、色）を毎日出すと、ほぼ重複した投稿として扱われやすく、表示も伸びにくい。X は会話が本体なので、無人の配信アカウントはミュートされやすい。

2026年の API は従量制。投稿1件が約0.015ドル、リンク付きは約0.20ドル。インスタの公式投稿 API のような、ビジネスアカウントの無料の毎日投稿ではない。

## LINE

LINE公式アカウントから、管理画面か Messaging API のブロードキャストで、友だちに同じメッセージを送れる。通数は「1回の配信 × 届く友だちの数」。1回に吹き出し3つまでなら1通。

| プラン | 月額（税別） | 月の無料通数 | 上限を超える追加 |
| --- | --- | --- | --- |
| コミュニケーション | 0円 | 200通 | 不可 |
| ライト | 5,000円 | 5,000通 | 不可 |
| スタンダード | 15,000円 | 30,000通 | 可。2026年10月1日から、20万通まで1通3円、それを超える分は1通2.5円 |

無料の200通だと、友だちが50人なら月4回まで。毎日出すと、友だちが7人を超えたあたりでその月は止まる。ライトでも、友だちが200人なら毎日は約6,000通になり、5,000通を超える。

受け取る側は、週1〜2回がブロックされにくい目安。LINE は通知が鳴るので、インスタのリールと同じ毎日には向かない。週1回、その週の色を1本、サイトへのリンクつきで出す。友だちが増えるまでは無料の200通で足りる。相手から送ってきたときの応答は通数に入らないので、「今日の色」はそちらに回す。

## Threads

公式 API で文章・画像・動画を出せる。料金はなく、インスタと同じく下書きを作ってから公開する。2025年9月以降は、インスタのアカウントと結ばなくてよい。

日本の人数は、2025年8月の調査で月に約1,230万人。同じ調査のインスタは約4,230万人、LINE は約7,080万人。2026年7月の Meta 発表では、世界の月間利用者は5億人を超え、日本の利用時間は前年の2.3倍。国内の人数そのものは公表されていない。

日本の Threads は、写真や動画より文章の投稿が多く、表示の半分以上が返信。毎日の色リールをそのまま置いても、会話の投稿に埋もれやすい。出すなら、その日のカードと色を短い文章にして、色のページへのリンクを添える。返事が付いたときに人が返す余地を残す。

## TikTok

Content Posting API がある。料金は従量ではなく、開発者アプリの審査で全体公開が開く。

- 直接投稿（`video.publish`）。キャプション付きで、その場で公開まで進む。
- 下書きへ送る（`video.upload`）。受信箱に入り、アプリで人が仕上げて出す。

動画は手元のファイルを送るか、公開 URL から取らせる。URL から取るには、そのドメインを開発者アプリに登録する。MP4（H.264）、長さは最大10分、容量は最大4GB。今の15秒リールはこの範囲に入る。1アカウントあたり1日およそ15本まで。

監査の前は非公開投稿だけ。アカウント自体も非公開である必要があり、24時間に投稿できるユーザーは5人まで。監査が通ると、全体公開の直接投稿ができる。

## YouTube ショート

リールはすでに 1080×1920、15秒なので、ショートの条件に入っている。2024年10月15日以降、正方形か縦で3分以内の動画は自動でショートになる。専用の API はなく、通常の動画と同じ `videos.insert` で出す。`#Shorts` は要らない。API は無料で、1日100本まで上げられる。

全体公開までの手続きが重い。Google Cloud で YouTube Data API を有効にし、チャンネルのオーナーが OAuth でアップロード権限を渡す。2020年7月28日より後に作ったプロジェクトは、コンプライアンス監査が通るまで、API からの投稿は非公開のまま。インスタのように公開 URL を渡す形ではなく、動画ファイルそのものを送る。

日本では YouTube の月間利用者が LINE に次ぐ規模で、ショートはその発見枠。毎日のオリジナル動画を予約で出すチャンネルは普通にあり、X のような無人投稿への拒否感は弱い。チャンネルはすでにあって、トップの「愚者の旅」をそこに埋め込んでいる。

監査が通るまでは、同じチャンネルの YouTube Studio からショートとして出す。API の自動化は、監査のあと。
