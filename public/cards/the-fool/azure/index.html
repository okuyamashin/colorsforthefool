THE FOOL · Azure

正位置 · #F0FFFF

「THE FOOL」は、まだ名前のない道へ足を上げるカードです。

荷物は小さく、犬は足元にいます。崖はあります。ただしこの向きの崖は、落ちるための穴ではありません。頭上の空が、歩ける広さとして見えている状態です。一歩は、空の広さに応じて出ます。

顔料の歴史では、空の色は石から作られました。瑠璃を砕き、何度も洗って、絵の上の空にします。旅人も同じことをします。遠くの山を一度に理解するのではなく、頭上の開き方だけを洗い出して、今日の一歩の大きさにします。空が低い日は歩幅が小さく、空が遠い日は荷物が軽く感じられます。

土地は、崖の上の一つの道です。

風が下から来ます。
犬は先に匂いを調べます。
花は手の中にあり、道標になります。
遠くの町は、まだ行く場所ではありません。

神話の旅人も、最初の日には空しか持っていませんでした。ヘルメスは道と境界を行き来し、旅人は空の明るい側を自分の右に置くことで方角を失いませんでした。道具は羅針盤である前に、頭上の面そのものです。

今日の動作は、大きく出発しなくてよいものです。

窓の外の空が、今日はどの高さにあるかを見る。
荷物を一つ減らし、犬がついてこられる大きさにする。
地図を広げる前に、靴紐を結び直す。
知っている道の、いつもより一本先の角まで歩いて戻る。

THE FOOLは、空が広いから飛びおりろとは言いません。
空が歩ける広さとして見えているなら、その一歩は軽い、と告げるカードです。

今日のラッキーカラーは、アジュールです。
Lucky Color: Azure — #F0FFFF崖の底を見ないで、頭上の開き方を見てください。
今日の幸運は、その高さに合わせた一歩にあります。
