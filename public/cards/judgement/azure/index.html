JUDGEMENT · Azure

正位置 · #F0FFFF

「JUDGEMENT」は、呼び声がすでに鳴っているカードです。

雲の上で角笛が吹かれ、石の蓋が開きます。人々は腕を上げます。返事は長い演説ではありません。立ち上がること、そのものが返事です。空は、その返事を受ける広い面です。

中世の画工は、最後の日の空を描くとき、瑠璃の石を砕いて顔料にしました。石は山から来ます。砕かれ、洗われ、薄い膜になって壁の上の空になります。呼び声も同じです。どこか遠い山の出来事が、いま見ている壁の、腕を上げた人の頭上に届きます。空は背景ではありません。呼び声が着地する場所です。

地理を一つにします。

海に面した町の、朝の空。
角笛の代わりに、港の鐘が一度だけ鳴ります。
棺の代わりに、夜のあいだ閉じていた窓の扉があります。
人は外へ出る前に、空の高さを一度見ます。

天候が澄んでいる必要はありません。雲があっても、雲の切れ目が一つの面を作れば足ります。歴史のなかで、旅立ちの朝に空を見た人は、方角を空に尋ねました。船も、行列も、野を行く人も、最初に確認するのは足元ではなく、頭上の開き方でした。

今日の動作は、その確認です。

窓を開け、空がどこまで続いているかだけを見る。
閉じたままの予定を一つ、扉のように開ける。
誰かの呼び声に、長い説明の前に短い返事を返す。
机の上の蓋、本のしおり、箱のふたを、一つ開ける。

JUDGEMENTは、空が割れて何かが降るとは言いません。
呼び声はもう鳴っていて、返事は立ち上がる動作だと告げるカードです。

今日のラッキーカラーは、アジュールです。
Lucky Color: Azure — #F0FFFF角笛の音を追わないで、音が届いた空の高さを見てください。
今日の幸運は、その開いた面にあります。
